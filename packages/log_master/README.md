# log-master (daemon and CLI)

The `log-master` distribution: the FastAPI daemon (`log-master serve`) that coordinates
recording across logging servers, proxies downloads and serves the web UI, and the
`log-master` CLI client. See the repository README and `SPEC.md` §6–§10.

| Module | Role |
|---|---|
| `app.py` | App factory; the lifespan starts the poll loop. |
| `config.py` | `config.yaml` models and comment-preserving edits. |
| `state.py` | The active-log state file. |
| `poller.py` | Polls `/v1/status` on every source. |
| `recorder.py` | Recording state machine: start/stop, late join, pending stops, adoption, warnings. |
| `listing.py` | Merges `/v1/logs` across sources. |
| `downloads.py` | Single-file (Range) and streaming-zip download proxy. |
| `api/` | REST routers under `/api/v1`. |
| `cli/` | Typer CLI. |
| `static/` | Built SPA (generated by `make frontend`, not committed). |
